Released 13 July 2026. Available on npm as [`orino-cli`](https://www.npmjs.com/package/orino-cli) and [`@bynaree/orino`](https://www.npmjs.com/package/@bynaree/orino).

```bash
npx orino-cli@latest audit
```

The audit JSON output now carries the raw PageSpeed Insights metrics as structured data, so programmatic consumers can render actual Core Web Vitals numbers instead of parsing them out of check messages.

## Added

- **Structured `psi` object in the JSON output.** [`auditToJson`](/changelog/v0-3-1) and `--json` now include a top-level `psi` field alongside `results`: the raw `lcp`, `cls`, `inp`, and `ttfb` values, the Lighthouse `score` (0–100), plus `lcpElement`, `opportunities`, `available`, and `strategy`. Previously these numbers survived only inside check messages (and the performance score wasn't exposed at all), so consumers had to parse prose. The `PSIData` type is now exported from the package. The field is `null` when PSI didn't run (no key, or a codebase-only audit). See [PSI setup](/docs/psi-setup) for how to configure a key.
